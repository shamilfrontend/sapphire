# Gateway API

Эта страница описывала корпоративный шлюз. Он больше не используется.

Сейчас чат, агент и автодополнение идут на endpoint выбранного провайдера. Список моделей и ошибки — [Модели и провайдеры](/intro/models) и [Ключ и ошибки](/intro/token-and-errors).

OpenAI-совместимые провайдеры по-прежнему говорят на `GET /v1/models`, `POST /v1/chat/completions` и, где есть FIM, `POST /v1/completions`. Anthropic и Gemini используют свои API.
