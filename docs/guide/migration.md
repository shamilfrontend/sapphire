# Миграция и импорт

## Import / Export

- экспорт настроек и чатов в JSON;
- импорт на другую машину;
- reset к дефолтам Sapphire.

Храните экспорты осторожно: в них могут быть локальные предпочтения; API-ключи остаются в encrypted storage IDE, не копируйте секреты в открытые чаты.

## Смена машины

1. Установите Sapphire.
2. Подключите провайдеров заново (API-ключ / endpoint) в Settings или онбординге.
3. При желании импортируйте settings/chats JSON.
4. Скопируйте `.rules` проекта из git, если они у вас в репозитории.

## Workspace-данные

Индекс и планы лежат в `.sapphire/` в корне workspace. Если ещё нет `.sapphire`, при первом обращении IDE переименует `.llm-ide`. Правила и скиллы: `.rules` / `.skills`; если их нет, читаются legacy `.voidrules` / `.voidskills`.
