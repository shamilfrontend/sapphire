# Inline Edit (Ctrl+K)

Правка **выделенного** фрагмента на месте, со стримингом и diff.

## Запуск

| Платформа       | Сочетание                    |
| --------------- | ---------------------------- |
| macOS           | <kbd>Cmd</kbd>+<kbd>K</kbd>  |
| Windows / Linux | <kbd>Ctrl</kbd>+<kbd>K</kbd> |

1. Выделите код.
2. Нажмите Ctrl/Cmd+K.
3. Опишите нужное изменение в quick-edit поле.
4. Модель стримит правку в **DiffZone** поверх выделения.
5. Примите или отклоните diff.

По умолчанию модель — `glm-5.3-flash`.

## Selection helper

При выделении текста может появиться overlay с подсказками Ctrl+L (в чат) и Ctrl+K (inline edit).

## Связь с Apply

Внутри используется тот же `editCodeService`, что и для Apply / tool `edit_file`, но DiffZone обычно меньше (только выделение, не весь файл).
