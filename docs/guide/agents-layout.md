# Режим IDE / Режим Агент

В Sapphire есть два **layout** интерфейса (`layoutMode` в Settings).

| Режим | Значение | Что видите |
| --- | --- | --- |
| **Режим IDE** | `ide` | Классический VS Code workbench: редактор, терминал, Explorer + сайдбар ассистента |
| **Режим Агент** | `agents` | Полноэкранный оверлей: дерево чатов (папки, pinned), композер и статус индекса проекта |

## Как переключить

- **Settings → Интерфейс** — карточки выбора режима.
- В **Режиме IDE** — кнопка **«Режим Агент»** справа в title bar (после онбординга).
- Command Palette: действие **Режим Агент** (`sapphireAgentsWindow` / переключение `layoutMode`).

В онбординге после токена можно сразу выбрать layout; позже смена всегда доступна в Settings.

## Чем отличается работа

- ChatMode (Chat / Plan / Agent), tools и approvals **те же** — меняется оболочка, не возможности модели.
- В IDE статус индекса проекта — в title bar; в Режиме Агент — в композере.
- В Режиме Агент удобнее вести много тредов и папок чатов без фокуса на файловом дереве.
