# Checkpoints

Checkpoints — снимки состояния файлов вокруг сообщений агента/чата.

## Зачем

После серии правок Agent можно **откатиться** к состоянию до определённого сообщения в треде (`jump to checkpoint`), не собирая git checkout вручную по каждому файлу.

## Как пользоваться

1. Ведите диалог в Agent/Chat с правками.
2. В истории треда используйте переход к checkpoint перед нужным сообщением.
3. Файлы восстанавливаются к сохранённому снимку.

Точная семантика реализована в `chatThreadService` (`jumpToCheckpointBeforeMessageIdx`).

## Не путать с git

Checkpoint — внутренний механизм IDE, не git-commit. Для постоянного сохранения истории по-прежнему используйте SCM.
