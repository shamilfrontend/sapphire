# Tab autocomplete

Inline-подсказки при наборе кода (как в Cursor / Copilot).

## Как работает

1. Вы печатаете в редакторе.
2. Сервис autocomplete отправляет **FIM**-запрос (`POST /v1/completions`) на шлюз.
3. Подсказка показывается серым текстом.
4. <kbd>Tab</kbd> принимает предложение.

По умолчанию используется модель **`qwen3-8B`** (единственная из дефолтного набора с FIM).

## Настройки

Вкл/выкл и модель FIM: **Settings → Опции → Автодополнение**. См. [Settings](/guide/settings#автодополнение).

## Ограничения

- Нужен валидный токен и доступ к шлюзу.
- Без FIM у модели качество/формат подсказки может быть непригодным — держите Tab на `qwen3-8B` или аналоге с fill-in-the-middle.
